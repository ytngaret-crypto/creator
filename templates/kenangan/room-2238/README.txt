ROOM 2238 — DYNAMIC TEMPLATE

Template ini hanya menyimpan desain/layout/animasi dari ROOM 2238 Lavender.
Foto, musik, dan seluruh teks contoh dari versi demo sengaja dihapus.

Data yang diisi pengguna melalui bot:
- judul: judul halaman pembuka/header/halaman terakhir
- nama: nama penerima
- subjudul: teks kecil di bawah judul
- intro_texts: beberapa baris untuk fase MEMORY / TEXT
- quiet_text: teks pada THE QUIET CHAPTER
- ending_main: pesan utama di tengah ending (1–2 baris)
- ending_texts: beberapa baris untuk floating text pada ending
- gallery: foto yang di-upload pengguna; jumlah bebas
- music: musik yang di-upload pengguna; opsional

Bot membuat salinan template untuk setiap website dan memasukkan data pengguna.
Template master tidak diubah oleh proses pembuatan website.
