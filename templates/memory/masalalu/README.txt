KENANGAN WEB — CLEAN TEMPLATE

Ini template kosong dari konsep web Kenangan.

YANG DIPERTAHANKAN:
- Background bintang biru/ungu
- Intro teks cinematic
- Sequence SS
- THE QUIET CHAPTER
- Ending floating text yang seimbang kiri/kanan
- Warna lavender
- Layout mobile-first

YANG DIHAPUS:
- Semua foto/screenshot asli
- Audio asli
- Teks kenangan asli
- Data pribadi dari web sebelumnya

BOT CREATE WEB:
Isi window.KENANGAN_CONFIG di index.html:
- title
- introTexts[]
- photos[]
- endingTexts[]
- quietChapter
- endingTitle
- music

Contoh:
photos: ["assets/photos/01.jpg", "assets/photos/02.jpg"]

Foto/audio baru dapat ditempatkan di assets/photos/ dan assets/audio/.
